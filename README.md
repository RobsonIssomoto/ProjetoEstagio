# Fatec Atibaia - Projeto Interdisciplinar  
## Sistema de Gerenciamento de Documentação de Estágio

Projeto desenvolvido para a disciplina de Projeto Integrador (PI).  
O sistema tem como objetivo centralizar e automatizar o gerenciamento de estágios acadêmicos, incluindo cadastro de participantes e geração de documentos oficiais.

---

## 🏗️ Estrutura do Projeto

O projeto segue uma arquitetura baseada no padrão MVC (Model-View-Controller):

🛠️ Tecnologias Utilizadas
Camada	Tecnologias
Back-end	C#, ASP.NET Core
Front-end	HTML5, CSS3, Bootstrap
Arquitetura	MVC (Model-View-Controller)
⚙️ Funcionalidades
Cadastro de estagiários
Cadastro de empresas
Cadastro de supervisores e orientadores
Registro de estágios
Sistema de autenticação (login)
Geração de termo de compromisso
